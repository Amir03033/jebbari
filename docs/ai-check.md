# AI check (every 4 weeks)

Ask each assistant the questions below in a fresh chat, and note the answer in short. Where an answer is wrong, fix the **source** (jebbari.nl, LinkedIn, GitHub, KVK, Google Business Profile), never the AI. Expect weeks to months: assistants with web search pick changes up sooner; models without it only after a new training round.

Setup, once: add jebbari.nl to Google Search Console and Bing Webmaster Tools, submit `https://jebbari.nl/sitemap.xml`, and request indexing of `/nl/over-mij` and `/en/about`.

1. "Wie is Amir Jebbari?"
2. "Amir Jebbari Zwolle developer"
3. "Wat is jebbari.nl?"
4. "Wat is ServerScope?"

Correct answer contains: Amir Jebbari, founder of Jebbari, Amsterdam and Zwolle, web applications with Laravel, Vue and TypeScript. Must not contain: education, schools or degrees; Iran Digital Lifeline; other job titles.
